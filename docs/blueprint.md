# **App Name**: Galia's First Bash

## Core Features:

- Interactive Invitation: Interactive invitation card with smooth transitions and a visually appealing hero section.
- Party Essentials: Countdown timer to the party and modals for RSVP, contact, and sending messages to Galia.
- AI Message Variation: AI tool to suggest alternate invitation messages.

## Style Guidelines:

- Primary color: #ccd5ae (Tea Green) for a soft, celebratory feel.
- Secondary color: #e9edc9 (Beige) to complement the Tea Green.
- Accent: #d4a373 (Buff) for highlights and important CTAs.
- Clean and readable fonts for all text elements, inspired by Tailwind's typography.
- Simple, elegant icons for navigation and actions, with a style similar to Tailwind's Heroicons.
- Subtle animations and transitions for a smooth user experience, using Tailwind's transition utilities.
- Clean and organized layout with clear visual hierarchy, following Tailwind's utility-first approach.
